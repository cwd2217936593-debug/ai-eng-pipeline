# 场景实例化（Scenario → 工况 → 设计约束）

> **Stage 0 的第二个产物**：`00d-场景工况.md`。
> 它回答一个问题：**这个东西要在什么条件下活着？**
> 前置：`00b` 已定领域。后置：G0.10 通过。

---

## 为什么场景比需求还靠前

用户说"做一个支架"，这句话里没有信息。
用户说"做一个装在冷库风机上的支架，-40℃ 到 +20℃ 循环，有凝露"，这才是一个工程问题。

区别在哪：

| | 需求 | 场景 |
|---|---|---|
| 回答什么 | 要什么 | 在什么条件下要 |
| 形态 | "支架，承重 20kg" | "-40℃ 凝露环境，年循环 300 次，维护周期 5 年" |
| 变了会怎样 | 改参数 | **换材料、换工艺、换验证方法** |

**同一个 M8 螺栓，装在不同场景，是六个不同的零件。**

| 场景 | 材料 | 镀层/表面 | 预紧力 | 防松 | 关键失效 |
|---|---|---|---|---|---|
| 冷库 -40℃ | 低碳钢有低温脆断风险，需低温冲击合格的材料 | 镀锌在低温+凝露下… | 低温下预紧力变化 | 弹簧垫圈在低温失效 | 低温脆断、凝露锈蚀 |
| 空调外机 | 碳钢 + 镀锌 | 需过盐雾 | 常温 | 螺纹胶 | 电偶腐蚀、振动松脱 |
| 食品车间 | 304/316 不锈钢 | 钝化 | | | 氯离子点蚀（清洗剂） |
| 户外钢结构 | 热浸锌 / 达克罗 | 盐雾 480h+ | | | 大气腐蚀 |
| 汽车底盘 | 10.9 级 + 达克罗 | | 扭矩+转角 | | 氢脆、疲劳 |
| 洁净室 | 316L + 电解抛光 | | | | 颗粒脱落 |

同一颗螺丝，六套答案。**如果 Stage 0 不问场景，后面所有设计都是在赌。**

而且赌注不对称：材料选错的代价不是"改一下"，是整批报废 + 现场失效 + 可能的召回。

## 场景八槽位（SC1–SC8）

每个槽位必须给出**具体值**。允许写 `N/A: <理由>`，不允许写"待定""视情况"。

| ID | 槽位 | 要问出什么 | 缺失的后果 |
|---|---|---|---|
| **SC1** | 使用环境 | 温度区间与极值、变化速率、温循次数；湿度；海拔；UV；粉尘 | 材料、密封、润滑、电池全错 |
| **SC2** | 介质与腐蚀 | 冷凝水、盐雾、清洗剂、化学品、油、食品接触 | 镀层选错，寿命差一个数量级 |
| **SC3** | 载荷 | 静载/动载/循环次数/冲击/振动谱/预紧 | 强度、疲劳、防松全错 |
| **SC4** | 寿命与维护 | 设计寿命、维护周期、可更换性、失效判定 | 选型偏保守或偏冒险，成本与风险双输 |
| **SC5** | 安装与空间 | 空间限制、可达性、装配顺序、工具、误装可能 | 设计出来装不进去，或装反 |
| **SC6** | 法规与认证 | 销售地、行业准入、安规、环保、阻燃 | 做到认证阶段才发现过不了，返工 4–6 周 |
| **SC7** | 失效后果 | 是否安全相关、可接受度、召回成本、可检测性 | 定不出合理的裕量与冗余 |
| **SC8** | 量与成本 | 批量、单件成本上限、交期、供应链 | 选了一个做不出来的工艺 |

**SC6 和 SC7 是最常被跳过的两个，也是最贵的两个。**
SC6 决定"能不能卖"，SC7 决定"要多保守"。跳过它们的设计，通常在量产前返工。

## 三级推导：SC → OP → DC

这是本文件的核心。**三级不许跳，跳了就是拍脑袋。**

```
SC（场景槽位，定性）
  ↓ 转译（这一步是专业能力所在）
OP（工况参数，带单位、带数值）
  ↓ 匹配（这一步靠标准/规则包/取证）
DC（设计约束，带判据来源）
  ↓ 落地
DF（设计特征：材料、尺寸、公差、工艺、接口）
```

### 示例：冷库支架螺栓（演示格式，数值均需按 §5 重新取证）

**第一级 SC**

```
SC1 使用环境: -40℃ ~ +20℃，每年化霜循环约 300 次，单次降温速率约 5℃/h
SC2 介质: 高湿（RH 95%），凝露，化霜水，无盐雾，无化学清洗
SC3 载荷: 静载 20kg（风机+支架自重），风机振动（转速 1400rpm）
SC4 寿命: 设计 10 年，维护周期 1 年，螺栓不可达（需拆风机才能换）
SC5 安装: M8，扳手空间 30mm，盲装，无对中工装
SC6 法规: 无强制认证；食品仓储 → 需符合食品接触/防脱落要求
SC7 失效: 支架脱落 → 风机坠落 → 制冷剂泄漏 + 停产；安全相关
SC8 量: 首批 500 套，目标单件 ≤3 元，交期 3 周
```

**第二级 OP（每条都要带数值和单位，且标注它来自哪一级 SC）**

| OP | 参数 | 值 | 来自 | 依据状态 |
|---|---|---|---|---|
| OP1 | 最低服役温度 | -40℃ | SC1 | E1 可查（低温试验等级） |
| OP2 | 温循次数（10 年） | 3000 次 | SC1×SC4 | 计算 |
| OP3 | 相对湿度 | 95% RH，持续凝露 | SC2 | E2 |
| OP4 | 振动 | 1400rpm 基频 ≈ 23.3Hz，加速度待测 | SC3 | **E3-待核** |
| OP5 | 安全系数要求 | 安全相关 → 需高于常规 | SC7 | 待定（见假设 A1） |

**第三级 DC（每条挂判据来源，来源只能是 EV 或 RULE）**

| DC | 约束 | 判据来源 | 落到哪个 DF |
|---|---|---|---|
| DC1 | 材料在 -40℃ 的冲击功须满足规定值 | RULE-xxx / EV-xx | 选材（碳钢 or 不锈钢） |
| DC2 | 表面处理须通过中性盐雾 ≥N 小时 | RULE-xxx | 镀层/钝化 |
| DC3 | 防松方式在 -40℃ 与振动下有效 | RULE-xxx / EV | 弹簧垫圈 or 螺纹胶 or 尼龙嵌件 |
| DC4 | 预紧力矩按润滑状态修正 | EV / RULE | 装配工艺卡 |
| DC5 | 失效不得导致部件坠落（二次锁止） | SC7 推导 | 结构（防脱结构） |

**注意 DC4 这类**：预紧力矩不是常数。同规格螺栓，干态、镀锌、涂 MoS₂ 的扭矩系数差 30% 以上。
抄一个"标准扭矩表"而不问表面状态，是这类设计最常见的错。

## 场景分类学（便于复用与挂规则包）

不要每次从零描述场景。用四域标签组合，标签直接决定挂哪些规则包。

| 域 | 取值 |
|---|---|
| **温度** | 常温 / 低温(-20~-60) / 深冷(<-60) / 高温(>100) / 温循 / 剧烈温变 |
| **腐蚀** | 干燥室内 / 凝露 / 盐雾 / 化工 / 食品清洗 / 土壤 / 海水 |
| **载荷** | 静态 / 疲劳 / 冲击 / 振动 / 压力密封 / 扭矩 |
| **法规** | 无 / 消费 / 工业 / 医疗 / 车规 / 航空 / 防爆 / 食品接触 |

组合成标签：`低温×凝露×振动×食品接触`

标签的三个用途：
1. 挂规则包（`rulepack.md` 的 `applies_to` 按标签匹配）
2. 判断攻击面（低温→脆断；凝露→电偶腐蚀；振动→松脱）
3. 复用（同标签的历史 run 可以直接参考其 DC 表）

## 输入缺口：用户给不出参数怎么办

**这是最真实的卡点。**用户经常说"我也不太清楚""你们专业你定"。

先把缺口分成两类，因为处置方式完全不同：

| 类型 | 定义 | 例子 | 处置 |
|---|---|---|---|
| **知识缺口** | 标准/规范里写了，只是还没查 | "低温螺栓用什么材料" | 走 `domain-discovery.md` 取证，能补 |
| **输入缺口** | 项目特定的，查不到，只有用户知道 | "这个冷库是 -25℃ 还是 -40℃" | 只能登记假设，或问用户 |

**判错的后果**：把输入缺口当知识缺口 → AI 编一个数值，看起来有依据（因为它"查过"）；
把知识缺口当输入缺口 → 明明能查却去问用户，用户嫌烦，随便给个数，更糟。

### 二分法操作

对每个空槽位问两句话：

```
1. 这个值在公开标准/规范里有定义吗？
   有 → 知识缺口 → 去查，查完标 E1/E2
   没有 → 下一问

2. 这个值是本项目特有的（取决于场地、客户、产能、预算）吗？
   是 → 输入缺口 → 问用户；用户答不出 → 登记假设
```

### 假设登记（输入缺口的唯一合法出口）

**核心规则：假设必须是具体值，不能是"待定"。**

```
❌ 假设：冷库温度按常规取值
✅ 假设 A1：最低温度按 -40℃ 设计（依据：用户口述"速冻库"，E3）
   影响：DC1 材料、DC3 防松、密封件选型
   若错：若实际为 -25℃，材料可降级，成本降约 15%——偏保守，安全
   谁确认：需方设备科 / 冷库设计方
   返工点：00d 的 SC1 + DC1/DC3 + AC（低温冲击试验项）
```

**登记表格式（写进 `00d` 第 5 节）**

| ID | 假设值 | 依据等级 | 影响的设计特征 | 若错的代价与方向 | 谁确认 | 返工点 |
|---|---|---|---|---|---|---|
| A1 | -40℃ | E3 | DC1,DC3,密封件 | 偏保守，成本 +15% | 需方设备科 | 00d/DC1/AC2 |

四列不能空：**依据等级、若错的代价（含方向：偏保守/偏冒险）、谁确认、返工点**。
"若错的代价"必须写方向 —— 偏保守是花钱，偏冒险是出事。这两种错完全不同。

### 假设数量上限（防滥用）

| 级别 | 上限 | 超了怎么办 |
|---|---|---|
| S | 2 条 | 回去问用户，别猜 |
| M | 5 条 | 挑影响最大的 3 条问，其余登记 |
| L | 8 条 | 开一次需求澄清会，把清单直接给用户 |

**超限说明需求根本没聊清楚。**继续做的结果是一份漂在 8 个假设上的设计，
任何一个假设塌了，整份作废。这时候暂停比推进便宜。

### 有假设时的结论口径

| 假设数 | 允许的结论 |
|---|---|
| 0 | `PASS` |
| ≥1 | **`PASS-WITH-ASSUMPTIONS`**，且必须列出假设清单与各自的返工点 |

**不允许在有未确认假设时给出无条件 `PASS`。** 这是 I5 在交付口径上的延伸：
让用户清楚知道"你拿到的是一个条件成立的交付"。

## 场景漂移（scenario drift）

干到一半场景变了。常见触发：
- 用户补充"其实这个也用在室外"
- 采购说某材料买不到，要换
- 试装发现空间不够

**处置流程**（不许就地改）：

```
1. 停。不进 Stage 1 后续。
2. 回 Stage 0，更新 00d（并保留原版本，不覆盖）
3. 影响分析，逐条过：
   - 哪些 SC 变了 → 哪些 OP 变 → 哪些 DC 变
   - 哪些 DF（已选的材料/尺寸）失效
   - 哪些 AC 作废（不是"改"，是作废重写）
4. 07 记 D# 裁决：变的是什么、谁提的、作废了什么、代价多少
5. 重过 G0.10 与受影响的 G1/G2/G3
```

**为什么不许就地改**：场景是上游，改动会沿着 SC→OP→DC→DF→AC 一路传导。
就地改一处，等于在一条已经算过的链子上换了个头，后面全是错的但看起来对。

## G0.10 · 场景门禁

全部满足才进入 Stage 1（与 G0 并行，任一不过都停）：

- [ ] `00d-场景工况.md` 存在且非空壳
- [ ] SC1–SC8 八个槽位都有具体值（`N/A` 必须带理由）
- [ ] OP 表 ≥3 行，每行有数值 + 单位 + 来自哪个 SC
- [ ] DC 表 ≥3 行，每行挂 `EV-` 或 `RULE-` 来源；纯项目自定约束可挂 `SC#`，但含数值的约束必须挂 RULE/EV
- [ ] 每条 DC 能落到一个 DF（材料/尺寸/公差/工艺/接口之一）
- [ ] 假设表每行四列齐全（依据等级、若错代价+方向、谁确认、返工点）
- [ ] 假设数 ≤ 该级别上限
- [ ] 场景标签已给出（四域组合）
- [ ] **用户已确认场景**（把 SC1–SC8 摘要读给用户，得到"对"）

**不过时怎么办**：退回 Stage 0 补 `00d`。
**不许带着未定的场景进入需求阶段** —— 需求是从场景推出来的，
场景没定，需求就是猜的，而猜出来的需求会一路通过所有后续门禁（因为它们只检查内部一致性）。

## 这条设计在防什么

| 失败模式 | 没有场景会怎样 | 有场景会怎样 |
|---|---|---|
| 材料选错 | "用 304 不锈钢总没错" → 成本翻倍，或氯离子环境下点蚀 | SC2 决定 304 还是 316 |
| 认证踩空 | 做到 EMC 测试才发现要过 3C | SC6 在选型阶段就锁定 |
| 参数拍脑袋 | "公差按 0.1 给" | DC 挂 RULE，出处可查 |
| 假设隐形 | 8 个假设埋在设计师脑子里，交付时无人知晓 | 全部登记，用户签字或在交付书上列出 |
| 场景漂移无人知 | 室外件按室内设计，一年后锈穿 | 漂移必须回 Stage 0，影响分析留痕 |

最后两行最重要。**假设和漂移本身不是错，隐形才是错。**
